# Hệ thống quản lý thư viện ảnh trực tuyến

## Mục tiêu
Xây dựng và triển khai hệ thống thư viện ảnh trực tuyến sử dụng Docker,
kết hợp quản trị cơ sở dữ liệu, sao lưu và giám sát hệ thống.

## Công nghệ
- Frontend: React + Vite
- Backend: Python Flask
- Database: PostgreSQL
- Reverse Proxy: Nginx
- Deployment: Docker Compose
- Monitoring: Prometheus + Grafana

## Cấu trúc
- frontend/: Giao diện người dùng
- backend/: API và xử lý nghiệp vụ
- database/: Cấu hình cơ sở dữ liệu
- nginx/: Cấu hình reverse proxy
- monitoring/: Giám sát hệ thống
- backup/: Sao lưu và phục hồi
- docs/: Tài liệu dự án
